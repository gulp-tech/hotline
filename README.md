# Hotline

Нарративная игра в стиле визуальной новеллы. Вы — дежурный оператора ночной горячей линии. Каждый звонок — это別ная жизнь, каждый выбор имеет последствия, а у каждого персонажа свой голос.

## Как запустить

Откройте `index.html` в любом современном браузере. Для локальной разработки можно использовать любой статический сервер, например:

```bash
python3 -m http.server 8000
```

## Персонажи и голоса

Каждый персонаж озвучен отдельным голосом (Web Speech API / предустановленные аудиодорожки):

- **Оператор** — вы, спокойный, рассудительный
- **Алексей** — паникующий абонент
- **Марина** — таинственная звонящая
- **Диспетчер** — ваш начальник, жёсткий, формальный

## Структура

- `index.html` — разметка и интерфейс
- `style.css` — стили и атмосферная графика
- `game.js` — игровая логика, диалоги, выборы
- `dialogue.js` — сюжет и реплики персонажей
